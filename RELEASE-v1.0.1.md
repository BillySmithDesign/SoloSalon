# SoloSalon v1.0.1

A small presentation release built on the stable v1.0 open-source package.

## Added
- Single-fold marketing landing page at `/`
- SoloSalon logo asset
- Direct GitHub CTA
- Live demo CTA to `/book`
- Open-source positioning and project philosophy on the homepage

## Existing routes preserved
- `/book` customer booking
- `/admin` stylist admin
- `/setup-check` installation checker

## Deployment
Replace the contents of your existing SoloSalon repository with this package,
commit and push to `main`. Vercel should redeploy automatically.

No Supabase database changes are required for v1.0.1.
