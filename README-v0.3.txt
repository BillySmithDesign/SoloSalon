SoloSalon v0.3 patch

1. Copy this patch over the existing SoloSalon repo.
2. In Supabase SQL Editor, run:
   supabase/migrate-v0.2-to-v0.3.sql
3. Ensure Vercel environment variables are configured.
4. Commit and push to main.
5. Visit /admin and complete the setup wizard.

New in v0.3:
- stylist/business profile + socials
- first-run setup wizard
- working-day/hour controls
- blocked time/time off
- service price, duration and buffers
- online-booking service visibility
- profile-driven booking page
